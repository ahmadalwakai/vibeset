# Vibeset — Data Model

Source of truth for the database schema, the `ThemeSpec` format and the theme status state machine. Code in `db/schema/*` and `lib/render/spec.ts` must match this file.

---

## 1. Conventions

- Postgres on Neon. Drizzle ORM, stable line. Column names are explicit snake_case strings (no `casing` option).
- Primary keys: `uuid` with `defaultRandom()`. Exception: Better Auth tables use `text` ids (generated by Better Auth).
- Domain timestamps: `timestamp(…, { withTimezone: true })`, `created_at` default `now()`, `updated_at` with `$onUpdate(() => new Date())`. Generated Better Auth tables preserve the CLI's UTC timestamp representation (currently PostgreSQL `timestamp` without time zone); never edit their generated columns to change it.
- Enums: `pgEnum`. Adding a value = a migration; never reuse/rename a value.
- Files loaded by external CLIs (`db/**`, `server/auth.ts`, `lib/env.server.ts`, `drizzle.config.ts`) use **relative imports** for runtime code. Aliased imports (`@/…`) are allowed only as `import type`.
- Denormalised counters (`download_count`, `favorite_count`, `popularity`) are caches. Source of truth: `theme_stats_daily` and `favorites`. Recomputed nightly by cron.

---

## 2. Better Auth tables (`db/schema/auth.ts`)

**Generated, never hand-written**: `npx dotenv -e .env.local -- npx auth@1.7.12 generate --config ./server/auth.ts --output ./db/schema/auth.ts --yes`. The official CLI package is now `auth`; keep its version aligned with the installed Better Auth runtime. The generated file is excluded from Prettier so regeneration preserves the CLI output.

On the first generation only, before the generated auth tables exist, configure the auth options without the database adapter and add `--adapter drizzle --dialect postgresql` to that command. Then wire the schema-aware adapter and regenerate from the complete `server/auth.ts`. All committed auth tables come from the CLI, including its relations. The schema index exports the generated tables plus account/session relations; `db/relations.ts` combines auth and domain user relations in one object to preserve Drizzle's relational typing.

Expected tables: `user` (+ admin plugin fields `role`, `banned`, `ban_reason`, `ban_expires`; + additional field `locale`), `session` (+ `impersonated_by`), `account`, `verification`, `rate_limit` (Better Auth's own limiter storage). Re-run the CLI whenever auth plugins/fields change, then `db:generate`.

Our tables reference `user.id` (text).

```ts
import { sql, type SQL } from 'drizzle-orm';
import {
  pgTable, pgEnum, uuid, text, jsonb, integer, boolean, doublePrecision, timestamp, index,
  type AnyPgColumn,
} from 'drizzle-orm/pg-core';
import { user } from './auth';
import { generationRuns } from './system';
import { tsvector } from '../custom-types';
import type { ThemeSpec } from '@/lib/render/spec';
import type { ThemeAssets } from '@/lib/theme-assets';

export const themeStatus = pgEnum('theme_status', [
  'draft', 'pending_review', 'approved', 'published', 'rejected', 'archived',
]);
export const themeSource = pgEnum('theme_source', ['generated', 'admin', 'creator', 'remix']);
export const colorFamily = pgEnum('color_family', [
  'pink', 'red', 'orange', 'yellow', 'green', 'teal', 'blue', 'purple',
  'brown', 'black', 'white', 'gray', 'multi',
]);

export const themes = pgTable(
  'themes',
  {
    id: uuid('id').primaryKey().defaultRandom(),
    slug: text('slug').notNull().unique(),
    status: themeStatus('status').notNull().default('draft'),
    source: themeSource('source').notNull(),
    ownerId: text('owner_id').references(() => user.id, { onDelete: 'set null' }),
    remixOfId: uuid('remix_of_id').references((): AnyPgColumn => themes.id, { onDelete: 'set null' }),

    nameEn: text('name_en').notNull(),
    nameAr: text('name_ar'),
    descriptionEn: text('description_en'),
    descriptionAr: text('description_ar'),

    spec: jsonb('spec').$type<ThemeSpec>().notNull(),
    specHash: text('spec_hash').notNull(),             // sha256 of canonical spec JSON
    assetVersion: integer('asset_version').notNull().default(0),
    assets: jsonb('assets').$type<ThemeAssets>(),       // null until first publish
    assetsSpecHash: text('assets_spec_hash'),           // specHash the assets were rendered from
    dominantColor: text('dominant_color'),
    colorFamily: colorFamily('color_family'),
    previewHash: text('preview_hash'),                  // 64-bit dHash of the 72×156 home wallpaper (16 hex chars), docs/05 §8

    tagsText: text('tags_text').notNull().default(''),  // "y2k Y2K واي تو كي pastel …" — maintained by services
    searchVector: tsvector('search_vector').generatedAlwaysAs(
      (): SQL => sql`
        setweight(to_tsvector('simple', coalesce(${themes.nameEn}, '')), 'A') ||
        setweight(to_tsvector('simple', coalesce(${themes.nameAr}, '')), 'A') ||
        setweight(to_tsvector('simple', coalesce(${themes.tagsText}, '')), 'B') ||
        setweight(to_tsvector('simple', coalesce(${themes.descriptionEn}, '')), 'C')`,
    ),

    isFeatured: boolean('is_featured').notNull().default(false),
    downloadCount: integer('download_count').notNull().default(0),
    favoriteCount: integer('favorite_count').notNull().default(0),
    popularity: doublePrecision('popularity').notNull().default(0),

    rejectionReason: text('rejection_reason'),
    publishError: text('publish_error'),
    generationRunId: uuid('generation_run_id').references(() => generationRuns.id, { onDelete: 'set null' }),

    submittedAt: timestamp('submitted_at', { withTimezone: true }),
    reviewedAt: timestamp('reviewed_at', { withTimezone: true }),
    reviewedBy: text('reviewed_by').references(() => user.id, { onDelete: 'set null' }),
    publishedAt: timestamp('published_at', { withTimezone: true }),
    createdAt: timestamp('created_at', { withTimezone: true }).notNull().defaultNow(),
    updatedAt: timestamp('updated_at', { withTimezone: true }).notNull().defaultNow().$onUpdate(() => new Date()),
  },
  (t) => [
    index('themes_pub_new_idx').on(t.publishedAt.desc(), t.id.desc()).where(sql`${t.status} = 'published'`),
    index('themes_pub_popular_idx').on(t.popularity.desc(), t.id.desc()).where(sql`${t.status} = 'published'`),
    index('themes_pub_downloads_idx').on(t.downloadCount.desc(), t.id.desc()).where(sql`${t.status} = 'published'`),
    index('themes_status_idx').on(t.status, t.updatedAt.desc()),
    index('themes_owner_idx').on(t.ownerId),
    index('themes_color_family_idx').on(t.colorFamily),
    index('themes_generation_run_idx').on(t.generationRunId),
    index('themes_search_idx').using('gin', t.searchVector),
  ],
);
```

## 5. `ThemeSpec` — the theme format (`lib/render/spec.ts`)

Render-agnostic design tokens. The web renderer, the generator, the admin editor and the Phase 2 native widgets all consume exactly this.

```ts
import { z } from 'zod';

export const GLYPH_WEIGHTS = ['thin', 'light', 'regular', 'bold', 'fill', 'duotone'] as const;
export const FONT_IDS = ['readex-pro', 'fraunces', 'pacifico', 'space-grotesk', 'el-messiri', 'jetbrains-mono'] as const;
export const PATTERNS = ['checker', 'gingham', 'dots', 'stripes', 'grid', 'y2k-grid', 'hearts', 'stars', 'bows', 'leopard'] as const;

export const Hex = z.string().regex(/^#[0-9a-fA-F]{6}$/).transform((v) => v.toLowerCase());
export const GlyphName = z.string().regex(/^[a-z0-9-]{1,48}$/);
export const Seed = z.number().int().min(0).max(2_147_483_647);
export const Unit = z.number().min(0).max(1);
export const AssetKey = z.string().regex(/^uploads\/wallpapers\/[0-9a-f-]{36}\/full\.jpg$/);
const Colors = z.array(Hex).min(2).max(6).nullable();        // null = derive from palette

export const paletteSchema = z.object({
  mode: z.enum(['light', 'dark']),
  bg: Hex, surface: Hex, primary: Hex, accent: Hex, ink: Hex, inkMuted: Hex,
});

export const wallpaperSchema = z.discriminatedUnion('kind', [
  z.object({ kind: z.literal('mesh'), seed: Seed, points: z.number().int().min(3).max(7), softness: Unit, grain: Unit, colors: Colors }),
  z.object({ kind: z.literal('blobs'), seed: Seed, count: z.number().int().min(3).max(9), blur: Unit, grain: Unit, colors: Colors }),
  z.object({ kind: z.literal('waves'), seed: Seed, layers: z.number().int().min(2).max(6), amplitude: Unit, frequency: Unit, grain: Unit, colors: Colors }),
  z.object({ kind: z.literal('pattern'), pattern: z.enum(PATTERNS), scale: z.number().min(0.5).max(3), rotation: z.number().min(-45).max(45), colors: Colors }),
  z.object({
    kind: z.literal('scatter'), seed: Seed, glyphs: z.array(GlyphName).min(1).max(6), weight: z.enum(GLYPH_WEIGHTS),
    density: Unit, sizeMin: z.number().min(0.02).max(0.2), sizeMax: z.number().min(0.03).max(0.35),
    rotate: z.boolean(), grain: Unit, colors: Colors,
  }),
  z.object({ kind: z.literal('aurora'), seed: Seed, bands: z.number().int().min(2).max(5), grain: Unit, colors: Colors }),
  z.object({ kind: z.literal('sky'), seed: Seed, mode: z.enum(['day', 'sunset', 'night']), clouds: Unit, stars: Unit, moon: z.boolean(), grain: Unit, colors: Colors }),
  z.object({ kind: z.literal('shapes'), seed: Seed, density: Unit, grain: Unit, colors: Colors }),
  z.object({ kind: z.literal('image'), assetKey: AssetKey, focalX: Unit, focalY: Unit, dim: z.number().min(0).max(0.6) }),
]);

export const iconStyleSchema = z.object({
  shape: z.enum(['squircle', 'circle', 'rounded', 'square']),   // Android/desktop exports only; iOS is always full-bleed
  fill: z.enum(['solid', 'gradient', 'glass', 'outline', 'pattern', 'wallpaper']),
  bg: Hex,
  bg2: Hex.nullable(),                                            // gradient end colour
  glyphColor: Hex,
  glyphWeight: z.enum(GLYPH_WEIGHTS),
  glyphScale: z.number().min(0.4).max(0.7),
  border: z.object({ width: z.number().min(0).max(0.08), color: Hex }).nullable(),
  sticker: z.object({ glyph: GlyphName, color: Hex, corner: z.enum(['tl', 'tr', 'bl', 'br']) }).nullable(),
  shadow: z.boolean(),
});

export const widgetStyleSchema = z.object({
  style: z.enum(['glass', 'solid', 'outline', 'paper']),
  radius: z.number().min(0).max(0.5),
  surface: Hex, ink: Hex, accent: Hex,
});

export const typographySchema = z.object({ display: z.enum(FONT_IDS), body: z.enum(FONT_IDS) });

export const themeSpecSchema = z
  .object({
    v: z.literal(1),
    palette: paletteSchema,
    wallpaper: wallpaperSchema,
    lockWallpaper: wallpaperSchema.nullable(),                    // null = same as wallpaper
    icons: iconStyleSchema,
    widgets: widgetStyleSchema,
    type: typographySchema,
    decor: z.array(GlyphName).max(6),
  })
  .superRefine((spec, ctx) => {
    for (const [path, w] of [['wallpaper', spec.wallpaper], ['lockWallpaper', spec.lockWallpaper]] as const) {
      if (w?.kind === 'scatter' && w.sizeMin > w.sizeMax) {
        ctx.addIssue({ code: 'custom', path: [path, 'sizeMin'], message: 'sizeMin must be ≤ sizeMax' });
      }
    }
    if (spec.icons.fill === 'gradient' && !spec.icons.bg2) {
      ctx.addIssue({ code: 'custom', path: ['icons', 'bg2'], message: 'gradient fill needs bg2' });
    }
  });

export type ThemeSpec = z.infer<typeof themeSpecSchema>;
export type WallpaperSpec = z.infer<typeof wallpaperSchema>;
export type IconStyle = z.infer<typeof iconStyleSchema>;
```

Rules:

- Optional values are `nullable` (explicit `null`), never omitted → canonical JSON is stable.
- `canonicalJson(spec)` sorts object keys recursively; `specHash = sha256(canonicalJson)` via `globalThis.crypto.subtle` (isomorphic). Lives in `lib/render/hash.ts`.
- Spec version `v: 1`. A breaking change adds `v: 2` + a pure `migrateSpec(any) → latest` function; old rows are migrated lazily on read and eagerly by a script.

## 6. Site settings (`site_settings.key`)

Each key has a shared Zod schema in `lib/settings.ts`, used by forms and `server/services/settings.ts`; reads fall back to defaults.

| Key | Value | Default |
|---|---|---|
| `home.hero` | `{ collectionSlug: string \| null }` | `{ collectionSlug: null }` (Home uses the first pinned collection) |
| `home.announcement` | `{ enabled: boolean; textEn: string; textAr: string; href: string \| null; tone: 'info' \| 'celebrate' \| 'warning' }` | `{ enabled: false, textEn: '', textAr: '', href: null, tone: 'info' }` |
| `features` | `{ creatorApplicationsOpen: boolean; uploadsEnabled: boolean; reportsEnabled: boolean }` | all `true` |

Announcement links accept safe app-relative paths or HTTP(S) URLs; protocol-relative paths, backslashes, control characters and URL credentials are rejected. Missing or invalid stored settings fall back to their complete per-key defaults.

Home hero collections must be public editorial/seasonal collections. Home applies seasonal windows to both explicit and pinned choices. A null, missing or currently ineligible selection falls back to the first eligible pinned collection, then the brand hero when none exists. Renaming a selected collection rewrites `home.hero.collectionSlug` atomically; deleting it clears the selection. These changes audit and invalidate both collection and settings data. Settings updates select and lock referenced collections before the settings row.

## 7. Theme status state machine

All status changes share the policy in `server/services/theme-status.ts`. `transitionThemeStatus({ themeId, to, actor, reason? })` validates actor rights and preconditions and commits the guarded change and audit atomically. Its conditional batch statement inserts an audit only when the update returns a row; conflicts never record a successful transition. Every transition into `published` is reserved for the publish service, which uses the same policy and a short interactive transaction for its final publication update and audit.

| From → To | Allowed actor | Preconditions / side effects |
|---|---|---|
| draft → pending_review | owner who is an approved creator | spec valid; name set; ≥ 1 aesthetic tag; sets `submitted_at` |
| draft → approved | admin | for `generated` / `admin` sources |
| pending_review → draft | owner (withdraw) | clears `submitted_at` |
| pending_review → approved | admin | sets `reviewed_at/by` |
| pending_review → rejected | admin | `reason` required → `rejection_reason`; sets `reviewed_at/by` |
| approved → rejected | admin | `reason` required |
| approved → published | **publish service only** | assets rendered & uploaded; sets `published_at` (first time), clears `publish_error` |
| rejected → draft | owner (on edit) | clears `rejection_reason` |
| rejected → approved | admin (override) | — |
| published → archived | admin | hidden from all public lists and pages (404) |
| archived → published | admin via publish service | renders a new immutable asset version; unchanged-publication skipping applies only while already published |

Rejection reasons normalize to plain text with control characters and excess whitespace removed. Accept 1–500 normalized characters (at most 2,000 raw characters); audit metadata stores only that normalized reason.

Edit rules:

- Owner may edit spec/names only in `draft` or `rejected` (editing `rejected` moves it to `draft`).
- Admin may edit in any status. Editing a `published` theme keeps it published but marks it **stale** (`assets_spec_hash ≠ spec_hash`) → shown in the publish queue for re-render.
- Remixes (`source = 'remix'`) stay `draft` and private forever unless the owner is an approved creator and submits them.

Delete rules: owner may hard-delete their `draft`/`rejected` themes; admin may hard-delete anything not `published` (archive first). Deletion removes R2 objects under `themes/{id}/` (best-effort, after the DB commit, using `after()`).

Public visibility = `status = 'published'` — every public query filters on it. No exceptions.
