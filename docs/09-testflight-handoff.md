# Vibeset — First TestFlight handoff · تسليم النسخة التجريبية الأولى

Prepared 24 October 2026. This is a provisional metadata and asset packet for the planned native companion. **Verify web P00–P17 first, then implement Expo through Codemagic.** Local web verification is recorded in [README](../README.md); remaining release gates are in [docs/08](08-quality-checklists.md). Passing those local checks does not establish live-provider readiness, real-device results or Apple approval.

أُعدّت هذه الحزمة في 24 أكتوبر 2026، وتضم مسودات بيانات وأصول التطبيق المرافق المخطط له. **الترتيب المعتمد: التحقق من الويب P00–P17 أولًا، ثم تنفيذ تطبيق Expo عبر Codemagic.** نتائج التحقق المحلي موثّقة في [README](../README.md)، وشروط الإطلاق المتبقية في [docs/08](08-quality-checklists.md). هذه النتائج لا تثبت جاهزية الخدمات الفعلية أو نجاح اختبارات الأجهزة الحقيقية أو موافقة Apple.

## 1. Current state · الحالة الحالية

- **Web:** implemented and locally verified; provider configuration, the performance budget, device checks and human legal review remain separate release gates. `npm run audit:bundles` reports an existing build; `npm run check:bundles` additionally fails at or above 180,000 gzip bytes on either Home locale. Neither command builds the app, and the check is not wired into CI while the budget remains unmet.
- **Native:** no `mobile/` project, widget extension, signing configuration or IPA exists in the repository. `codemagic.yaml` builds the web server only. No Apple app record, team, identifier or TestFlight upload is verified by this packet. See the implementation and signing sequence in [docs/07 §7](07-roadmap-phase2-native.md#7-first-testflight-readiness--24-october-2026).
- **الويب:** منفّذ ومتحقق منه محليًا، مع بقاء إعداد الخدمات وميزانية الأداء واختبارات الأجهزة والمراجعة القانونية البشرية شروطًا مستقلة. الأمر `npm run audit:bundles` يعرض تقرير البناء الموجود، ويفشل `npm run check:bundles` إذا بلغ JavaScript المضغوط لصفحة البداية 180,000 بايت أو تجاوزها في أي لغة. لا ينفّذ أي منهما بناءً جديدًا، ولم يُربط الفحص بـ CI ما دامت الميزانية غير مستوفاة.
- **التطبيق الأصلي:** لا يوجد مشروع `mobile/` أو امتداد ودجت أو إعداد توقيع أو ملف IPA في المستودع. ملف `codemagic.yaml` مخصص لبناء الويب. لا تثبت هذه الحزمة وجود سجل تطبيق أو فريق أو معرّفات لدى Apple، ولا رفع نسخة إلى TestFlight. تسلسل التنفيذ والتوقيع في [docs/07 §7](07-roadmap-phase2-native.md#7-first-testflight-readiness--24-october-2026).

## 5. Future “What to Test” checklist · قائمة الاختبار المستقبلية

Select only completed features for each build; this is an acceptance plan, not a passing test report.

تُختار الميزات المنجزة فقط لكل بناء؛ هذه خطة قبول وليست تقرير نجاح.

- Install on a real iPhone; verify the build number, startup, offline/error recovery and accessible EN/AR/RTL layouts. ثبّت النسخة على iPhone حقيقي، وتحقق من رقم البناء وبدء التشغيل والعمل دون اتصال والتعافي من الأخطاء وإتاحة الواجهات بالعربية والإنجليزية.
- Browse the actual catalogue; verify theme details and native save/share without granting unrelated permissions. تصفّح المحتوى الفعلي وتحقق من التفاصيل والحفظ والمشاركة الأصلية دون أذونات غير لازمة.
- Add each implemented widget family; verify shared theme persistence, refresh/timeline behaviour, relaunch and offline display. أضف كل نوع ودجت منفّذ، وتحقق من حفظ الثيم وتحديثه وإعادة التشغيل والعرض دون اتصال.
- If accounts or uploads are offered, verify sign-in/out, deletion, reporting, permissions and real data handling; preserve optional statistics defaults. إذا توفرت الحسابات أو الرفع، اختبر الدخول والخروج والحذف والإبلاغ والأذونات ومعالجة البيانات، مع الحفاظ على افتراضات الخصوصية للإحصاءات الاختيارية.
- Record archive/upload, Apple processing, tester assignment and a successful device install separately. External testing has additional review requirements; no approval or date is promised. [TestFlight overview](https://developer.apple.com/help/app-store-connect/test-a-beta-version/testflight-overview/). سجّل الأرشفة والرفع والمعالجة وتعيين المختبرين ونجاح التثبيت كمراحل منفصلة. للاختبار الخارجي متطلبات مراجعة إضافية، ولا يوجد ضمان للموافقة أو موعدها. [نظرة عامة](https://developer.apple.com/help/app-store-connect/test-a-beta-version/testflight-overview/).
